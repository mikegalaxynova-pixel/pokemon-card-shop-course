## 为什么买卖二手卡需要这份许可

买卖二手 PSA 卡在日本通常属于**古物营业（古物営業）**，必须先取得都道府县公安委员会的**古物商许可（古物商許可，こぶつしょうきょか）**。英文常称 antique dealer license / secondhand dealer license，但对外沟通时仍以日文正式名称「古物商許可」为准。

- 许可下来之前不能以古物商身份收购或经营二手卡，**不是「先开再补办」**。
- **即使货是朋友提供的**，只要作为店铺持续出售，通常仍应取得许可，并记录「从谁、何时、取得了什么」。
- 买入、寄售还是其他安排，法律评价可能不同，买卖安排见[古物台账、本人确认与入货记录]({{ '/kb/shop/kobutsu-records/' | relative_url }})，必要时向管辖警察署或行政书士确认。

## 仍需记住的参考信息

{% include figure.html src="/assets/img/kobutsusho-points.svg" alt="许可要点示意图：窗口按店址管辖警察署办理，手续费 19000 日元且不退，标准处理期间 40 日，品目须向管辖警察署确认。本图不是官方表格，也不再展开申请步骤" width="600" height="250" credit="本站示意图（依据警視庁公开说明整理）" credit_url="https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/tetsuzuki/kyoka.html" %}

| 项目 | 内容 |
| --- | --- |
| 申请窗口 | **按营业所地址，向管辖警察署办理**（东京多为防犯係／生活安全担当课）。本站不再列出某一署的电话或办理步骤。 |
| 手续费 | **19,000 日元**，不许可或撤回也不退 |
| 处理时间 | 东京都公安委员会审查基准写明标准处理期间为 **40 日（不含行政机关休息日）**，补件会更久 |
| 品目 | 古物分 13 类，交易卡实务上多按「道具類」申报，但条文没单独写「卡片」，以管辖警察署确认为准 |
| 管理者 | 每个营业所要有一名能实际履职的管理者，个人开店常由本人兼任 |

计划中的店址在东京高田马场（高田馬場 / Takadanobaba，新宿区）。窗口以该地址的管辖警察署为准，不要沿用已经过时的「到某一家署办理」写法。

## 许可之后，真正影响开店的是买卖记录

许可办下来，就可以依法开展收购和二手销售。那时每天真正要用的，不是申请材料，而是：

- 向卖方做本人确认；
- 把交易记入古物台账（或电磁记录），并保存；
- 怀疑是不正品时立即向警察申告。

这些写在[古物台账、本人确认与入货记录]({{ '/kb/shop/kobutsu-records/' | relative_url }})。
